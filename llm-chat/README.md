# LLM Chat — OpenRouter Edition

Real-time AI chatbot using React + Socket.IO + Node.js + OpenRouter.
Access 200+ models including many FREE ones (Llama, Mistral, Gemma, Qwen).

## Quick Start

### Terminal 1 — Backend
```
cd server
npm install
npm run dev
```

### Terminal 2 — Frontend
```
cd client
npm install
npm run dev
```

Open → http://localhost:5173
Login → demo@example.com / demo1234

## Your OpenRouter Key
Already saved in server/.env — just run and it works!
